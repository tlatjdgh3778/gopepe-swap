## 1. 목표

`README.md`를 앱을 쓰는 사용자 관점으로 다시 쓴다. 채용 검토자용 내용(알려진 한계 등)을 빼고, 한 줄 소개·앱 링크·스크린샷·경고·기능·사용 방법·지원 범위·기술 스택·로컬 실행·테스트를 한국어 "~합니다"체로 담는다. 기능은 F9 달러 환산, F10 네트워크 수수료, F11 배치 실행까지 반영한다. [사용자 결정]

- 아직 없는 기능(Permit2, Uniswap V4, 멀티홉, 크로스체인)의 소개 [사용자 결정]

### 3.2 내용

- DoD-6: 경고가 메인넷 실자산 동작, 앱(프론트엔드)이 보안 감사를 받지 않았다는 점, 무제한 승인 요청 세 가지를 담는다. 컨트랙트가 감사를 받지 않았다고 쓰지 않는다 — 검증: 코드 대조 [제안 후 승인]
- DoD-7: 기능이 다음 4개 항목이다. 수수료 티어 4개 견적 중 최다 수령 풀 선택, 금액·잔액의 달러 가치 표시(Uniswap 견적 기반), 다음 트랜잭션 수수료 미리 보기와 5% 이상·ETH 부족 안내, EIP-5792 배치 지원 지갑의 승인·스왑 한 번 확인 — 검증: 코드 대조 [사용자 결정]
- DoD-8: 사용 방법이 네트워크 선택·지갑 연결 → 토큰·금액 입력 → 예상 수령량·달러 가치·수수료 확인 → 승인·스왑 전송의 4단계다 — 검증: 코드 대조 [제안 후 승인]
- DoD-9: 지원 범위 표가 네트워크(Ethereum, Base, Arbitrum 메인넷), 지갑(EIP-6963 브라우저 확장 지갑, 예시는 MetaMask만), 토큰(체인별 기본 토큰 목록과 체인별 대략 개수), 스왑(Uniswap V3 단일 홉, exactInput, ETH ↔ WETH 전환) 4행이다 — 검증: 코드 대조 [사용자 결정]
- DoD-10: 지원 범위의 체인별 토큰 개수가 `config/tokens-1.json`·`tokens-8453.json`·`tokens-42161.json`의 항목 수와 10단위 반올림으로 일치한다 — 검증: 코드 대조 [사용자 결정]
- DoD-11: 수치(수수료 티어, 5% 경고 기준)가 코드 상수(`FEE_TIERS`, `NETWORK_FEE_WARNING_BPS`)와 일치한다 — 검증: 코드 대조 [제안 후 승인]
- DoD-12: 로컬 실행 섹션의 환경 변수 집합이 `.env.example`의 변수 3개와 정확히 같고, Node·bun 버전이 `.nvmrc`·`package.json` `packageManager`와 같다 — 검증: 코드 대조 [제안 후 승인]
