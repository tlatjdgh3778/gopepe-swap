## 시안 A 상태 보완 (2026-11-10)

- 시안 원본은 별도 시안 프로젝트에서 관리한다. 이 저장소에는 기준 PNG와 디자인 문서만 반영한다.
- 달러 환산·가스 가격·`실시간 견적 시안` 배지를 제거했다. 환율 행과 견적 정보 다섯 행은 유지한다. 수수료 티어는 읽기 전용이다.
- 슬리피지는 0.1% · 0.5% · 1.0% 프리셋만 사용하며 기본은 0.5%다.
- 가격 영향: 3% 이하 `--accent`, 3% 초과~15% 이하 `--warning`, 15% 초과 `--error`. 플레이그라운드에서 4.21%와 18.40%를 확인할 수 있다.
- `--warning: #e8c38b`는 앰버 계열이다. WCAG sRGB 상대 휘도는 0.5805로 `--error`(0.5363)와 비슷하다. `--surface: #191d1b` 위 대비는 **10.23:1**로 일반 텍스트 AA·AAA 기준을 충족한다 (`--error`는 9.51:1).
- 견적 계산 중에는 받는 금액과 예상 수령량·최소 수령량·가격 영향·수수료 티어를 `--raised` pulse 스켈레톤으로 표시한다. 동작 줄이기 환경에서는 애니메이션을 멈춘다.
- 직접 풀 없음(ETH↔WETH 포함), 입력 전, RPC 견적 실패에서는 견적 정보를 숨기고 받는 금액을 비운다. 입력 전 placeholder는 `0`이다. RPC 실패 버튼은 `견적을 가져올 수 없음`, 비활성이다.
- 지갑 미연결 예시에서도 견적을 표시하며 주 버튼은 `지갑 연결`이다. 모든 값은 가상이며 외부 API나 지갑 연결을 호출하지 않는다.
