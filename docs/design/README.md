# 디자인 기준

방향은 시안 A(다크 + 민트)다. 기준 스크린샷은 `wireframe/`에 있다. 시안 코드는 그대로 넣지 않고 아래 값을 `app/globals.css` 토큰으로 옮겨 쓴다.

## 이름

- 표시명: `GOPEPE Swap`
- 로고: 미정. 정해질 때까지 글자만 쓴다.

## 폰트

저장소에 설정된 Geist와 한글 시스템 폰트를 쓴다.
